## Featured Projects

### IoT Metadata for Video Editing
Repository: IoT_Metadata_for_Video_Editing

A system designed to support structured metadata extraction and organisation for video-based workflows. The goal is to improve how video content can be indexed, searched, and annotated using structured event-based data.

Key focus areas:
- Metadata structuring for media content
- Event-based tagging systems
- Workflow support for video editing environments
- Prototype-level integration with content pipelines

---

### KV6021 Machine Learning Project
Repository: KV6021_machine_learning

A machine learning-focused academic project implemented in Jupyter Notebook format. The work explores model training, evaluation, and dataset-driven experimentation.

Key focus areas:
- Data preprocessing and cleaning
- Supervised learning workflows
- Model evaluation and comparison
- Notebook-based experimentation and reporting

### FightNight
Repository: FightNight

A game development project created during a competitive game jam environment, achieving a top-tier placement.

Key focus areas:
- Rapid prototyping under time constraints
- Gameplay loop design
- Team-based development workflow
- Iterative balancing and testing

### FloodMappingLondon
Repository: FloodMappingLondon

A Python-based geospatial analysis project focused on modelling and visualising flood risk patterns in London using structured datasets.

Key focus areas:
- Geospatial data processing
- Environmental dataset analysis
- Mapping and visual representation
- Risk pattern identification
